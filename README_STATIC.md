# Falling Pickaxe static site

Сайт использует только физические HTML-файлы, CSS3 и vanilla JavaScript. Реальные HTTP-заголовки Last-Modified, ETag, Content-Encoding, 301/404, серверная аналитика, нагрузочное тестирование, индексация в Яндекс Вебмастере и Google Search Console требуют настройки на хостинге. Идентификаторы аналитики намеренно не добавлены.
